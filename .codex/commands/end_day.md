# End Day Command

Atualize quando necessário:

- `.ai/memory/current_feature.md`
- `.ai/memory/technical_debt.md`
- `.ai/decisions/`
- `.ai/reviews/`

Depois:

1. resuma progresso do dia
2. liste pendências
3. liste riscos
4. liste melhorias futuras
5. proponha próximos passos

## Regras

- Não invente progresso.
- Separe o que foi feito do que ficou pendente.
- Registre technical debt real.
- Crie review diário em `.ai/reviews/` quando solicitado.
