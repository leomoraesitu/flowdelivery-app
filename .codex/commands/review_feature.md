# Review Feature Command

Leia:

- `.ai/context/*`
- `.ai/agents/reviewer/*`
- `.codex/workflows/04_code_review.md`

Faça review rigoroso da feature atual.

Analise:

- bugs
- SOLID
- MVVM
- Clean Architecture
- acoplamento
- escalabilidade
- naming
- performance
- rebuilds desnecessários
- testabilidade
- separação de responsabilidades
- anti-patterns Flutter
- isolamento do Supabase
- uso de Riverpod quando presente

Não altere arquivos durante o review.
