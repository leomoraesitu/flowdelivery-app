# Create ADR Command

Leia:

- `.ai/templates/adr_template.md`
- `.ai/context/architecture.md`
- `.ai/decisions/`

Depois:

- crie ou proponha uma nova decisão arquitetural
- use o próximo número sequencial disponível
- explique contexto, decisão, tradeoffs, consequências e alternativas
- não altere decisões existentes sem confirmação

## Uso

```text
Leia:
.codex/commands/create_adr.md

Decisão:
Usar pacote X para Y.
```
