# FlowDelivery v0.3.0

Release date: 2026-07-03

## Objective

Publish the first interactive commerce slice on top of the validated v0.2.0
read-only catalog browsing experience: a session-local shopping cart built in
Sprint 9.

## Included

- Session-local shopping cart owned by a Riverpod `Notifier<Cart>` domain
  boundary (no repository/datasource; persistence deferred to Checkout).
- "Add to cart" action on product details, switching to in-cart quantity
  controls through a derived per-product selector.
- Single-restaurant constraint enforced in the domain (`CartAddResult`
  return signal) with a localized confirmation dialog.
- Protected `/cart` route gated by the centralized GoRouter auth guard.
- `CartPage` with localized empty and non-empty states, quantity controls
  with a remove affordance at quantity 1, per-item subtotal, running total,
  and a visible-but-disabled checkout CTA with placeholder copy.
- Cart item-count badge (`Badge` M3, hidden at zero) on restaurant and
  product hero headers, navigating to `/cart`.
- Shared `formatPriceInCents` utility replacing duplicated price formatting
  in restaurant/product details sections.
- 21 new `cart*` localization keys (pt_BR template, pt, en) including an
  ICU plural item count.
- README, routing conventions, and project bootstrap documentation
  reconciled with the implemented sprints 3-9 state, plus a recorded cart
  demo gif.

## Web Deployment

- Live demo: **https://leomoraesitu.github.io/flowdelivery-app/**
- Publishing is unchanged from v0.2.0: `.github/workflows/deploy-web.yml`
  deploys the Flutter web build to GitHub Pages automatically on each
  `v*.*.*` tag, with `--base-href "/flowdelivery-app/"` and the SPA
  `404.html` fallback.
- The password recovery redirect keeps preserving the project subpath,
  covered by `test/app/routes/auth_recovery_redirect_test.dart`.
- Manual step (owner action, unchanged): the Supabase Auth URL allow-list
  must include the Pages Site URL and the
  `/flowdelivery-app/reset-password` redirect.

## QA Evidence

- Real Trello story 45/45 in `🎉 Done`: `https://trello.com/c/VFGNIm0O`.

## Known Limitations

- Cart state is session-only by design; totals reset on app restart.
  Persistence lands with the Checkout slice.
- Delivery address, promo code, and delivery fee shown in the cart
  prototype remain deferred to Checkout.
- The Android build reports an existing `CupertinoIcons` asset warning,
  unchanged from v0.2.0 and outside this release scope.
