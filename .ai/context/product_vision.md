# FlowDelivery AI Context — Product Vision

## Product Summary

FlowDelivery is a delivery application portfolio project focused on a professional, recruiter-grade implementation of a food delivery experience.

## Product Goals

The project should demonstrate:

- solid Flutter architecture
- clean MVVM separation
- Supabase-ready backend integration
- consistent design system usage
- practical project management
- AI-assisted development governance
- release-quality documentation

## MVP Direction

Initial product areas:

- authentication
- restaurant feed
- product browsing
- cart
- checkout
- order tracking
- user profile

## Portfolio Goal

The repository should be understandable by recruiters, reviewers and future collaborators.

This means:

- clear documentation
- predictable structure
- validated changes
- consistent naming
- small reversible tasks
- evidence of engineering judgment

## Scope Discipline

Prefer incremental delivery.

Do not add advanced features before the MVP foundation is stable.

Future ideas such as analytics, AI delivery insights and advanced realtime logistics should remain outside MVP unless explicitly selected.
