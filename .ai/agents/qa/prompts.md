# Agent — QA — Prompts

## Test Plan

```text
Crie um plano de testes para esta feature.
Inclua happy path, edge cases, regressões e comandos de validação.
```

## Generate Tests

```text
Gere testes focados para o comportamento descrito.
Isole dependências externas e valide estados de UI quando aplicável.
```

## Release Validation

```text
Revise se esta mudança está pronta para release.
Liste evidências, riscos e validações pendentes.
```
